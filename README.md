## 🤖 Robôneuro

O **Robôneuro** é um aplicativo mobile desenvolvido para auxiliar na interação de crianças neurodivergentes com um robô educativo e interativo.
Esse projeto não é de minha autoria, sendo apenas uma atividade passada pelo professor de mobile!!!!

## 🎯 Objetivo

O objetivo do Robôneuro é criar uma experiência de interação entre **criança, aplicativo e robô**, utilizando atividades lúdicas e jogos para estimular diferentes habilidades de forma adaptável e divertida.

## 🎮 Jogos

A seção de jogos contará com atividades interativas, como:

* 🔴 **Jogo das cores**
* 🔊 **Jogo dos sons**
* 🧠 **Memória**
* 🔢 **Sequências**

## 📚 Atividades

As atividades serão organizadas de acordo com diferentes áreas de interação:

* 😊 **Emoções**
* 💬 **Comunicação**
* ✋ **Coordenação**
* 📅 **Rotina**

## 🤖 Meu Robô

Área destinada ao gerenciamento e controle do robô:

* 🔗 **Conectar robô**
* 📡 **Status**
* 🎨 **Personalizar**
* 🎮 **Comandos**

A comunicação entre o aplicativo e o robô poderá permitir que as atividades realizadas no celular provoquem respostas e ações no robô.

## 📊 Progresso

O aplicativo poderá acompanhar a interação da criança com as atividades:

* 📝 Atividades realizadas
* ⏱️ Tempo de interação
* ⭐ Conquistas

## ⚙️ Configurações

Área destinada à personalização da experiência, incluindo configurações de:

* 🔊 Som
* 📳 Vibração
* 🎨 Interface
* 🔔 Notificações
* 🤖 Configurações do robô
